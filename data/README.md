# Source Data

This folder contains source knowledge and reference inputs for the Events workflow.

| Folder | Description |
|:---|:---|
| **atomic_dataset/** | Original ATOMIC CSVs. |
| [**events/**](events/README.md) | Selected event inputs used by the generation pipeline and the 35 selected generation inputs for Phi4-mini. |

Generated, cleaned, and validated event datasets belong under [`experiments/events/results/`](../experiments/events/results/README.md).

The [human validation area](../human_validation/events/README.md) contains form creation, human-analysis code, form data, and comparison reports. The human-filtered event dataset remains an Events result.
